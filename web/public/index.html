"차단되었습니다" 메시지가 뜨면…

  1. 차단 알림에서 "완료"를 누릅니다. (이 단계에서 멈춰도 괜찮습니다)
  2. 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
  3. 보안 섹션에 "ClaudeCode-Installer.pkg이(가) 차단되었습니다" 메시지 옆 "그래도 열기" 버튼을 누릅니다.
  4. Touch ID 또는 비밀번호로 확인하면 설치가 진행됩니다.
  1. "PC 보호" 창에서 "추가 정보"를 누르세요.
  2. 아래에 새로 나타나는 "실행" 버튼을 누릅니다.
  3. 설치 마법사가 시작됩니다.

왜 경고가 뜨나요? 도티오가 코드 사이닝 인증서를 아직 발급받지 않았기 때문입니다. 신뢰하실 수 있도록 인스톨러의 전체 소스를 GitHub에 공개해 두었습니다.

claude-installer-psi.vercel.app
투명하게

정확히 무엇이 깔리는지 알려드릴게요.

  • ✓ Claude Code — Anthropic의 공식 명령행 도구 ~75 MB
  • ✓ Node.js 20 LTS — 이미 깔려 있으면 건너뜁니다 ~80 MB
  • ✓ Git — 이미 깔려 있으면 건너뜁니다 ~45 MB
설치 위치 · macOS: /usr/local/ · Windows: C:\Program Files\
총 용량 · 약 200MB (이미 설치된 항목은 제외)
자세히 보기 — 환경변수, 검증 방법

설치 후 PATH에 다음 경로가 자동으로 추가됩니다: macOS는 /usr/local/bin, Windows는 %USERPROFILE%\AppData\Roaming\npm. 기존 환경변수는 백업본을 함께 남깁니다.

설치가 잘 되었는지 확인하기 (smoke test). 새 터미널을 열고 claude --version을 입력하세요. claude-code 2.x.x가 출력되면 준비 완료입니다.

제거하기. macOS는 /Applications/Claude Code Uninstaller.app, Windows는 제어판 → 프로그램 추가/제거에서 동일한 이름으로 제거할 수 있습니다.

자주 묻는 질문

설치 전에 궁금하신 것들.

회사 노트북에 깔아도 되나요?

대부분의 경우 가능합니다. 다만 회사 정책상 다음 세 가지를 확인해 주세요:

① 관리자 권한. 설치 중 한 번 비밀번호를 묻습니다. 회사 계정으로 관리자 권한이 없다면 IT팀에 30초만 부탁하세요. ② 백신 / EDR. 일부 보안 솔루션이 인스톨러를 일시 격리할 수 있습니다. 격리 해제 또는 예외 등록이 필요합니다. ③ 사내 프록시. 첫 실행 시 api.anthropic.com과 registry.npmjs.org로 외부 호출이 발생합니다. 차단된 환경이라면 IT팀에 도메인 허용을 요청하세요.

한글로 된 사용자 이름을 쓰는데 괜찮나요?

네, 자동으로 감지해서 안전한 경로를 우선 사용합니다. macOS는 한글 사용자 폴더에서도 문제없이 동작합니다. Windows의 경우 %USERPROFILE% 경로에 한글이 포함되면 일부 npm 패키지가 깨질 수 있어, 인스톨러가 C:\Users\Public\claude-code\를 대신 사용합니다.

이 동작은 설치 마법사 첫 화면에서 끄거나 바꿀 수 있습니다.

이미 Claude Code가 깔려있어요

걱정 마세요. 인스톨러가 기존 설치를 자동으로 감지합니다. 구버전이 발견되면 백업한 뒤 최신 버전으로 업데이트만 진행하고, 같은 버전이면 아무것도 건드리지 않습니다. 설정 파일(~/.claude/)은 항상 그대로 유지됩니다.

삭제하려면 어떻게 하나요?

설치된 항목과 함께 언인스톨러도 같이 깔립니다. macOS는 /Applications/Claude Code Uninstaller.app을 더블클릭하면 됩니다. Windows는 설정 → 앱 → "Claude Code"에서 제거할 수 있습니다.

완전히 수동으로 정리하고 싶다면, 터미널에서 claude uninstall --purge를 실행하세요. 설정 파일과 캐시까지 모두 지웁니다.
