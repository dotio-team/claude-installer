이 인스톨러는 도티오(주식회사 도티오)가 비개발자의 Claude Code 도입을 돕기 위해 무상으로 제공하는 오픈소스 도구입니다.

이 인스톨러가 하는 일

  • 이 컴퓨터에 Node.js 20 LTS가 없으면 Node.js 공식 사이트(nodejs.org)에서 .pkg를 내려받아 설치합니다.
  • Xcode Command Line Tools(Git 포함) 설치 여부를 확인합니다.
  • npm을 통해 @anthropic-ai/claude-code를 글로벌로 설치합니다.
  • 설치 로그를 ~/Library/Logs/ClaudeInstaller/install.log에 저장합니다.

도티오가 수집하지 않는 것

이 인스톨러는 어떤 개인정보도 외부로 전송하지 않습니다. 텔레메트리도 없습니다.

코드 사이닝

이 인스톨러는 아직 Apple Developer ID로 서명되어 있지 않습니다. macOS에서 "확인되지 않은 개발자" 경고가 뜰 수 있으며, 우회하는 방법은 안내 페이지에서 확인하실 수 있습니다. 신뢰하실 수 있도록 인스톨러의 전체 소스를 GitHub에 공개해두었습니다.
